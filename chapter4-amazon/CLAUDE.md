# 爆鼠闖天下－亞馬遜吃瓜子 第四章
BooMMouse Goes Wild – Amazon, Chapter 4

小老鼠版貪食蛇。共四關，每關背景圖越來越清晰，第 4 關破關後揭曉完整成果圖、頒發勳章，還能下載紀念圖。
系列共通規則（語言、風格、開發原則、去背流程）見根目錄 `../CLAUDE.md`，這裡只寫本章。

## 技術
- 純 HTML + CSS + JavaScript，不用框架、不用 ES modules
- 直接雙擊 index.html 就能玩；js 用一般 `<script>` 依序載入：`i18n.js` → `levels.js` → `assets/versions.js` → `game.js`
- 遊戲主體用 Canvas 畫小老鼠隊伍、瓜子和畫面上的字；背景成果圖不進 Canvas（見下方「背景圖」）

## 遊戲規則
- 控制：在圖上滑動手指、畫面上的方向鍵、鍵盤方向鍵或 WASD；空白鍵或「暫停」按鈕暫停；切到別的分頁會自動暫停
- 每關一開始小老鼠不動，畫面顯示「第 N 關」和「選個方向出發！」，等玩家選方向才出發
- 吃一顆瓜子，後面多跟一隻小老鼠寶寶
- 好朋友小老鼠：破過別章的話（localStorage `boommouse-amazon-chN-cleared`，看到勳章時記錄），每關吃到第 1 顆瓜子時，那些章的小老鼠照章節順序一起來排隊（每走一步從隊尾出來一隻，不算瓜子數）；之後每吃一顆多一隻，從本章和破過的章隨機挑；沒破過別章就全是本章的小老鼠
- 走出邊緣會從另一邊回來（不會撞牆）
- 碰到自己的隊伍可以直接穿過去，不會失敗（`levels.js` 的 `PASS_THROUGH = true`）
- `PASS_THROUGH = false` 時：撞到自己的隊伍 = 失敗，顯示暈倒圖和「哎呀！」，從**當關**重新開始（不回第 1 關）
- 吃滿該關瓜子數 = 過關；過關卡片出現的同時，背景換成下一關的模糊度（小朋友會看到圖變清楚）
- 隊伍只有主角時可以直接迴轉；有寶寶之後不能直接迴轉

## 棋盤
- 20 × 12 格，比例 5:3（與成果圖 640 × 384 相同）
- 實際大小跟著螢幕縮放：寬度最多佔滿版面，高度不超過「視窗高度 − 300px」，平板橫拿會很大，手機直拿會比較矮（卡片會自動縮小）
- 瓜子隨機出現，不會在隊伍身上，也不會離主角頭太近（距離至少 3 格）

## 四關設定
| 關卡 | 背景 | blur | 瓜子數 | 速度 (ms/步) |
|---|---|---|---|---|
| 1 | 素面底色 `#beb8ae` | — | 8 | 180 |
| 2 | 成果圖，很模糊 | 20px | 12 | 150 |
| 3 | 成果圖，中度模糊 | 10px | 16 | 120 |
| 4 | 成果圖，輕微模糊 | 4px | 20 | 100 |

```js
// levels.js
const LEVELS = [
  { blur: null, seeds: 8,  speed: 180 }, // 第1關 素面
  { blur: 20,   seeds: 12, speed: 150 },
  { blur: 10,   seeds: 16, speed: 120 },
  { blur: 4,    seeds: 20, speed: 100 }, // 第4關
];
```
- `#beb8ae` 是從成果圖紙張取的顏色，讓第 1 關到第 2 關色調連貫
- 瓜子數與速度為暫定值，實玩後再調。第 4 關又快又長，小朋友卡關時先把速度調慢（例如 130–150）
- 測試模式：網址後面加 `?test`（例如 `index.html?test`），每關只要吃 1 顆就過關，方便快速看破關揭曉與勳章

## 背景圖
成果圖是**動畫 GIF**，Canvas 的 `drawImage` 只會畫第一格。
所以背景圖**不畫進 Canvas**：`<img id="bg">` 疊在透明 Canvas 後面，模糊用 CSS `filter` 控制（`game.js` 的 `setBg()` / `applyBg()`）。
- blur 數值以 640px 寬為準，畫面變大會等比放大
- 遊戲中背景透明度 0.72，並放大 1.06 倍蓋掉模糊造成的邊緣淡化；第 1 關透明度 0（只看到底色）
- 讓隊伍和瓜子在圖上看得清楚：瓜子有白色光暈，寶寶腳下有白色橢圓，主角腳下有黃色光圈

## 破關揭曉（第 4 關吃完最後一顆瓜子）
時間從吃到最後一顆算起：
1. 0.4 秒：Canvas 淡出，背景 blur 1 秒內從 4px 變成 0、透明度變 1，完整成果圖出現（老鼠走路動畫）
2. 清晰圖停留約 1.5 秒
3. 2.9 秒：淡入半透明暗色遮罩，勳章從上方落下（4.0 秒時播放勝利音效）
4. 勳章落下後，一隻戴名牌（玩家名字）的小老鼠從左邊走進來，站在大老鼠後面的小路上（640×384 圖上約 (290,300)）
5. 4.4 秒：棋盤下方的方向鍵換成勳章卡：「小老鼠 XXX 獲得亞馬遜勳章！」＋「下載這張圖」＋「再玩一次」
   ＋「去玩其他章節」：其他章的連結（圖是 `assets/friends/chN.png`），已完成的黃底「已完成 ✓」，沒完成的虛線框「還沒完成」（`renderChapters()`）

位置原則：
- 勳章放在圖的左上角（CSS：left 8.5% 是中心點、top 3%、寬 13%；Canvas：左邊 2%、上面 3%），畫面和下載圖要一致
- 勳章和小老鼠都不能蓋住老鼠（右側）和面具（左側）的主體；成果圖下方的版權字與簽名保留不遮
- 勳章文字放在棋盤下方的卡片，不寫在圖上

## 下載紀念圖
- 「下載這張圖」產生 1280×768 PNG：成果圖第一格＋勳章＋戴名牌的小老鼠，檔名 `BooMMouse-Amazon-ChN-名字.png`
- 雙擊開啟（file://）時，Canvas 畫了本機圖檔會被瀏覽器禁止匯出，所以下載用 `assets/export-data.js` 裡的 base64 圖，第一次按下載時才載入
- 換了 reveal.png 或 mouse.png 之後，在根目錄跑 `python tools/sync-chapters.py`（會一起更新各章的 friends 圖）
- 勳章在 Canvas 上用和 index.html 裡 SVG 相同的路徑重畫（`drawMedal()`），兩邊改其中一個時要一起改

## 音效（Web Audio 即時合成）
- 吃瓜子：兩聲短促的「咔咔」
- 撞到自己：軟軟的「咚～」（不要嚇人）
- 過關：叮叮叮；破關：上行琶音＋和弦
- 主角「吱吱」：出發、轉彎時叫一聲，直走時每 1.5～3 秒叫一聲，畫面上主角頭上冒「吱」
- 寶寶「吱」：隨機挑一隻寶寶叫，每隻音高不同、比主角小聲，頭上冒小小的「吱」；寶寶越多越熱鬧（每隻平均約 4 秒叫一次，整隊每秒最多約 3 聲）
- 「聲音：開／關」按鈕一次關掉全部音效

## 畫面文字
- 中文／英文兩版，所有文字（包含 Canvas 上的「第 N 關」「選個方向出發！」「哎呀！」「吱」）都在 `i18n.js`
- HTML 用 `data-i18n`（文字）、`data-i18n-ph`（placeholder）、`data-i18n-aria`（aria-label）標記；會帶數字或名字的字由 `game.js` 的 `renderFail()`、`renderClear()`、`renderMedal()` 產生，切換語言時會重畫
- 切換按鈕：開始畫面右上角、遊戲區下方各一個；「← 所有章節」（連回 ../index.html）在開始畫面左上角和遊戲區最上面的狀態列（第一個膠囊）各一個
- `<title>` 和開始畫面大標跟著語言換：英文版大標 BooMMouse Goes Wild，小字是中文；中文版大標爆鼠闖天下，小字是英文
- 英文版內文字型改用 Baloo 2

## 玩家名字
- 開始畫面輸入，最多 12 個字，存在 localStorage `boommouse-name`，下次自動帶入
- 用在勳章卡文字、小老鼠名牌、下載檔名；沒填時勳章卡寫「小老鼠獲得亞馬遜勳章！」，名牌寫「小老鼠」
